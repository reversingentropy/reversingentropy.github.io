Projects

NLB · Production
KOS Pipeline - Automated Knowledge Base Population
A semi-automated pipeline that reads Singapore news articles and proposes structured, evidence-backed updates to NLB's knowledge organisation system. Articles are classified, BM25-indexed against the full TTE controlled vocabulary, then passed through a two-stage LLM call that extracts structured facts and links them to existing entities. Every proposed change traces to an exact sentence in the source. 9,057 event updates and 2,319 new entity candidates in the current review queue - no writes without human approval.
BM25 LLM Pipelines Entity Linking Streamlit Knowledge Graphs

NLB · Production
Entity Resolution of 1.45M Records
A three-phase pipeline reconciling 1.45M personal name authority records against 12M Library of Congress records. Deterministic SQL joins handle 48% instantly. MiniLM embeddings + IVFFlat ANN search + XGBoost reranker handle the rest. 95.2% F1 on the hardest cases. Built on a single laptop with no GPU cluster.
